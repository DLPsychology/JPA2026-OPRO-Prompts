# Available Materials

This repository contains the Human Judge Rubric, the meta-prompts used for OPRO-based prompt optimization, and the best-performing prompts obtained under each condition.

These materials are provided as supplementary materials for the poster presentation at the 90th Annual Convention of the Japanese Psychological Association (JPA 2026).
