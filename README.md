# Best-performing Prompts for OPRO-Based Prompt Optimization

This repository provides the best-performing prompts obtained through OPRO-based prompt optimization for conspiracy belief classification.

These materials are provided as supplementary materials for the poster presentation at the 90th Annual Convention of the Japanese Psychological Association (JPA 2026).

- Detailed meta-prompt condition
